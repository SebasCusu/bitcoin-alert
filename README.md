# Bitcoin Alert Algorithm

A simple Python script designed to monitor Bitcoin prices and trigger automated alerts based on custom market thresholds.

## Features
- Real-time Monitoring: Tracks current Bitcoin prices using live API data.
- Custom Alerts: Notifies you immediately when Bitcoin hits your target price.
- Automated Script: Easy to run locally from any terminal.

## Prerequisites
Before running this project, make sure you have Python installed on your system. You might also need to install the requests library to handle API calls:

```bash
pip install requests
```

## How to Install and Run

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project folder:
   ```bash
   cd bitcoin-alert
   ```
3. Run the script:
   ```bash
   python bitcoin_alert.py
   ```
